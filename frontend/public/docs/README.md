# ImperiumAI – Diploma documents

Drop your diploma artefacts here so they are served by the website.

| File name | Purpose | Linked from |
| --- | --- | --- |
| `ImperiumAI_Diploma.docx` | Main Word diploma document | `/documentation` |
| `ImperiumAI_Diploma.pdf` | PDF export of the diploma | `/documentation` |
| `ImperiumAI_Presentation.pptx` | Defence presentation | `/documentation` |

Team photos go in `frontend/public/team/` as `1.png`, `2.png`, `3.png`.

If a file is missing, the Documentation page shows a notice instead of breaking.
